# DD-20: Hit and Run's attuned text 'any empty square adjacent to it' means adjacent to the square the piece moved from; the origin square itself stays an option

Status: binding under D-37 (designer may overrule).
Spec: 5.7

## Decision

Hit and Run's attuned text 'any empty square adjacent to it' means adjacent to the square the piece moved from; the origin square itself stays an option.

## Why it is the best case

'It' refers to the square named in the base effect; the attuned version widens the same retreat.
