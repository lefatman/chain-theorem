# DD-36: Silence uses the elements fixed when the move is committed (a promoting pawn counts with its pre-promotion element); attunement uses the bearer's element when the ability resolves

Status: binding under D-37 (designer may overrule).
Spec: 6.2, 6.3, R-RULES-002

## Decision

Silence uses the elements fixed when the move is committed (a promoting pawn counts with its pre-promotion element); attunement uses the bearer's element when the ability resolves. Negation takes precedence over silence.

## Why it is the best case

One capture has one elemental matchup; per-piece attunement follows R-RULES-002 for the promoted piece's new set.
