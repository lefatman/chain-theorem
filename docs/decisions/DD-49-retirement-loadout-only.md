# DD-49: Retirement is a loadout rule only (R-LOAD-004 rule 7): a retired module cannot be equipped in a new loadout, but the engine resolves every module a running battle started with, including retired triggered abilities, so battles and replays play the same way

Status: binding under D-37 (designer may overrule).
Spec: 13.5, R-LOAD-004

## Decision

Retirement is a loadout rule only (R-LOAD-004 rule 7): a retired module cannot be equipped in a new loadout, but the engine resolves every module a running battle started with, including retired triggered abilities, so battles and replays play the same way.

## Why it is the best case

13.5: each battle records its content version so replays load the same modules; skipping retired triggers mid-battle changed outcomes while retired items and passives still ran.
