# DD-28: Veil hides the ability name for activation, silence, negation and fizzle reveals; explicit REVEAL effects (Scout, Last Word, Pierce, Poisoned Meat attuned) still name veiled abilities

Status: binding under D-37 (designer may overrule).
Spec: 8.2, 5.7

## Decision

Veil hides the ability name for activation, silence, negation and fizzle reveals; explicit REVEAL effects (Scout, Last Word, Pierce, Poisoned Meat attuned) still name veiled abilities. The first time Veil hides a name, the opponent learns that piece type is veiled.

## Why it is the best case

A passive is revealed when its rule difference is observable (8.2); explicit reveals are tools that should beat concealment.
