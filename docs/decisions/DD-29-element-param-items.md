# DD-29: Attunement Charm and Masquerade Mask are single item modules with an element parameter chosen in the loadout; one owned copy covers every element

Status: binding under D-37 (designer may overrule).
Spec: 7.2

## Decision

Attunement Charm and Masquerade Mask are single item modules with an element parameter chosen in the loadout; one owned copy covers every element.

## Why it is the best case

Keeps the catalogue at the specified 11 items and avoids six near-duplicate modules.
