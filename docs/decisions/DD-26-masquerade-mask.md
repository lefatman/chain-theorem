# DD-26: Masquerade Mask shows one chosen element for all of the wearer's pieces (hiding Blended Family too) until the first silence event that involves any of the wearer's pieces in either direction; then the true elements show and the Mask is revealed

Status: binding under D-37 (designer may overrule).
Spec: 7.2, 8.1

## Decision

Masquerade Mask shows one chosen element for all of the wearer's pieces (hiding Blended Family too) until the first silence event that involves any of the wearer's pieces in either direction; then the true elements show and the Mask is revealed.

## Why it is the best case

Either direction of a silence exposes the true element relationship, so the bluff ends there.
